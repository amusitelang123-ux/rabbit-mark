# 2026-10-14

## 新增：用户端「站内公告」只读模块

背景：`notices` 表既有完整后台 CRUD（`adminMarketingService`）与种子数据，但用户端没有任何读取入口，属于真实缺口。

新增文件（不改动既有代码）：
- `server/src/services/noticeService.ts` — `listPublished(limit)` 只取 `status=1` 且 `publish_at` 为空或已到时间，按发布时间倒序，limit 夹取 1..50；`getPublished(id)` 未启用/不存在抛 404。
- `server/src/controllers/client/noticeController.ts` — `list` / `detail`，沿用 `asyncHandler` + `sendOk` + `toInt`。

既有文件仅两处加法（无删改）：
- `server/src/routes/client/index.ts` — 增加 `import * as notice ...`，以及文件末尾挂载 `GET /notices`、`GET /notices/:id`。
- `README.md` — API 概览表补一行「公告」。

约定备忘：
- 本项目 Bash 工具在此环境不可用（`dirname`/`ls`/`tail` 缺失），PowerShell 的 stdout 也不回显；验证命令需把输出写入文件再用 Read 读取（UTF-8 写入）。
- 类型检查：`server` 目录下用受管 Node 跑 `tsc --noEmit`，本次 EXIT=0 通过。
- DTO/时间格式沿用 `utils/serializers.ts` 的 `formatDate`，响应统一 `{code,message,data,timestamp}`。
